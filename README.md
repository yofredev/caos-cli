# CHAOS 🚀
### **C**ore **H**ub for **A**rchitecture and **O**rganizational **S**tructure

A lightweight, high-performance CLI tool written in Rust designed to automate core boilerplate generation based on Clean Architecture principles. 

CHAOS eliminates the friction of setting up structured backend projects by scaffolding your application's core layers, entities, and use cases instantly—preventing code entanglement right from the very first line.

## ✨ Features

* **Domain-Driven Directory Layout:** Automatically generates standard directories for domain logic, data sources, and adapters following strict Clean Architecture patterns.
* **Rust-Powered Speed:** Built entirely in Rust for near-instant execution, minimal footprint, and zero runtime dependencies.
* **Smart Boilerplate Automation:** Reduces manual setup, ensuring your project structure remains cohesive, decoupled, and ready to scale.
